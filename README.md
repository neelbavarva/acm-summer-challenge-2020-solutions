## About

This repository has 38 solutions: 29 in Java and 9 in C++. Each file is named after its problem and is a complete program that reads input from standard input and prints the answer, in the format the contest's online judge expected.

## Running a solution

Java solutions can be run directly with Java 11 or later:

```bash
java "Counting.java" < input.txt
```

C++ solutions use `<bits/stdc++.h>`, so compile them with GCC:

```bash
g++ -std=c++17 -O2 "Very Easy.cpp" -o solution
./solution < input.txt
```
